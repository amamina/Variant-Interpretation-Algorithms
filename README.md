# Variant-Interpretation-Algorithms
Next generation sequencing generates thousands of genetic variants, and researchers develop various protocols with multiple parameters in order to classify them. This work shows some efforts to computational exploration of algorithms underlying SIFT, PolyPhen-2, CADD, PROVEAN, SNP&amp;GO, MutationAssessor, Align-GVGD, PANTHER, P-Mut, and related tools.
